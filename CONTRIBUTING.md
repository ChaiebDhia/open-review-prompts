## Merge Rule
A prompt edit merges only if it:
1. Ships with the eval delta on the frozen held-out set (recall by concern type, 5 repeats, interval).
2. Does not lower recall on merit concerns.
3. Cites the public report or editor decision that motivated it.

Argument alone never merges.

## Rejection Template
"Thanks for this. I cannot merge it because of rule [n]. The evidence needed is [X]. Add it and reopen, and I will rerun the eval within 7 days."
